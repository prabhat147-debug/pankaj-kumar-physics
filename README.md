## 🚀 How to Run Locally

You can run the website immediately on your computer:

### Option 1: Direct File Opening
Double click `index.html` in your file explorer. It will open in Google Chrome, Edge, or your default browser.

### Option 2: Local HTTP Server (Recommended)
Open PowerShell in this directory and run:
```powershell
python -m http.server 8000
```
Then visit: `http://localhost:8000` in your web browser.

## 🌐 Publishing to GitHub & GitHub Pages (Free Live Website)

To publish this website to GitHub so that it has a public link (e.g. `https://<your-username>.github.io/physics-mentorship`):

### Automated Way:
Run the included helper:
```bat
push_to_github.bat
```
or run:
```powershell
python push_to_github.py
```
This script will prompt for your GitHub repository URL (or personal access token) and push the entire website with one click.

### Manual Git Steps:
1. Create a new empty repository on [GitHub.com](https://github.com/new) (e.g. named `pankaj-kumar-physics`).
2. Run these commands in this directory:
   ```bash
   git add .
   git commit -m "Launch Er. Pankaj Kumar Physics website"
   git branch -M main
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/pankaj-kumar-physics.git
   git push -u origin main
   ```
3. Go to your repository settings on GitHub:
   - Click **Settings** $\rightarrow$ **Pages** (on the left menu).
   - Under **Branch**, select `main` and root `/`, then click **Save**.
4. Within 1 minute, your website will be live worldwide at:
   `https://<YOUR-GITHUB-USERNAME>.github.io/pankaj-kumar-physics/`!
